# Documentation

## Purpose

This folder contains the technical and methodological documentation supporting the HR Analytics project.

The documents explain the analytical framework, business questions, dataset fields and decision-making process used throughout the project.

## Contents

- `BUSINESS_QUESTIONS.md` — defines the business questions addressed by the analyses.
- `data_dictionary.md` — documents dataset fields used in the project.
- `methodology.md` — explains the analytical workflow, classification system and evidence standards.

## Dependencies

The documentation supports:

- SQL analyses in `../sql/`
- Business deliverables in `../reports/`
- Data validation in `../data/`

## Rules

- One topic per document.
- Avoid duplicated information.
- Every analytical conclusion must remain traceable to SQL and data.
- Working notes and internal project management files are not published in this folder.
