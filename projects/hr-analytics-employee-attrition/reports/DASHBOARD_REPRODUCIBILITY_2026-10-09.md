# HR Analytics — reproducible aggregate dashboard inputs (2026-10-09)

## Distinguish the deliverables
- `excel/HR_Attrition_Evidence_Dashboard.xlsx` is the **static** seven-sheet workbook stored in GitHub and linked from the portfolio. It was committed as an XLSX and the Git blob hash was verified, but desktop Microsoft Excel compatibility is **not yet verified**.
- `excel/hr_dashboard_group_metrics.csv` is the **privacy-minimal aggregate source table**, generated by programmatic aggregation of the tracked original 1,470-row CSV. It has **28 summary rows**, not employee-level records.
- `python/build_dashboard_source.py` is a standard-library implementation of the **deterministic aggregation logic** for rebuilding the CSV. It does **not** currently rewrite, refresh, or recalculate the Excel workbook automatically.
- `tests/test_dashboard_source.py` holds **nine unit tests** for denominators, rounding, tenure band boundaries, duplicate/invalid input and CSV injection avoidance.

## Rebuild from the original data (from the project root)

```bash
python python/build_dashboard_source.py
python -m unittest discover tests -v
```

The script reads `data/raw/WA_Fn-UseC_-HR-Employee-Attrition.csv` and overwrites the **aggregate CSV** only, not the preserved raw input and not the Excel file. Optional `--source` and `--output` flags are provided for controlled tests. It never exports `EmployeeNumber` or the original employee-level records.

## Verified evidence
- Original CSV Git blob at the time of this check: `b8531237e39eccb4f3c87ee840c3dfbb6cdbce3b`.
- Original CSV dimensions: **1,470 rows, 35 columns**, **237 attritions**.
- Aggregate CSV overall: **16.1224%**, overtime Yes **127/416 = 30.5288%**, overtime No **110/1,054 = 10.4364%**. Percent values are explicitly percentage points in the CSV field, not fractions.
- There are 28 group rows across overall, overtime, job role, department, job satisfaction, work-life balance and tenure groups. Each breakdown's employee counts total 1,470.
- Local Python 3.13.5 execution of unit tests against **byte-for-byte Git-blob-matched** script/test files: **9/9 PASS**. This tests aggregation behavior on small controlled samples. The summary table was independently derived from the full GitHub raw CSV; **the Python rebuild against all 1,470 records was not separately executed in that same local environment**, so that end-to-end comparison remains a pending QA gate.

## Interpretation
Differences across groups are descriptive, not causal: this is the public IBM educational example, not measurements from an actual workplace. A higher attrition rate within a group is a starting hypothesis for confounder-aware investigation, not an intervention or proof that an employment practice causes departures.
